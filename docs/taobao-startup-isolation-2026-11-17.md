# 淘宝启动与网络隔离记录（2026-11-17）

## 当前结论

淘宝业务尚未恢复。alpha.9 的请求状态观察正常工作；本轮淘宝原生实验功能全部关闭。启动前移除两层证书覆盖、恢复原始 149 张平台证书后，新的购物车请求仍收到 HTTP 419；再同时停用淘宝的 HMA 过滤和 AliLoginCompat 作用域，也仍进入官方拒绝页。

第四轮恢复后，Wi-Fi 条件下取得的新首页响应仍为 419；购物车采样时已切回蜂窝，尚未完成稳定 Wi-Fi 的购物车对照。下文将第三轮结束状态与第四轮新增结果分别记录，不把某个错误码等同于已定位的服务器规则。

## 启动前移除 MagiCap 覆盖

使用独立临时程序观察新启动的淘宝主进程。程序用 pidfd、包名、UID 和启动时间限定目标，确认其挂载命名空间独占，暂停所有目标线程后再检查已加载库和挂载结构。只有已知 SG 库尚未映射、路径结构符合预期且不存在共享传播时才继续。

先执行不修改挂载的启动对照，再执行移除覆盖的试验：

| 检查 | 不修改挂载的对照 | 移除 MagiCap 覆盖 |
| --- | --- | --- |
| 暂停至恢复 | 31 ms | 31 ms |
| 已知 SG 库映射 | 未发现 | 未发现 |
| 普通 umount 次数 | 0 | 2 |
| 目标进程恢复 | 已确认 | 已确认 |
| 非目标挂载快照 | 3 个均未变 | 3 个均未变 |
| 超时或部分变更 | 无 | 无 |

试验只移除了淘宝进程内 /apex/com.android.conscrypt/cacerts 和 /data/local/tmp/sys-ca-copy 顶层的 MagiCap bind。原生状态改写、probe、business trace 和环境兼容均保持关闭，实际加载日志确认 native_hooks=skipped。

移除后，新响应 mtop.trade.query.bag 在过滤器入口为 HTTP 419，后续读取为 ANDROID_SYS_API_41X_ANTI_ATTACK；请求记录时间均晚于目标进程恢复。另一次恢复普通继承挂载后的蜂窝网络启动也产生新的购物车 HTTP 419。没有用拒绝页消失或响应缺失作为成功标准。

这说明：在已知 SG 库映射前移除上述 MagiCap 覆盖，仍不足以恢复本次购物车业务。它不证明不存在更早的 Java 初始化、继承状态、历史服务端状态或其他环境影响。

独立克隆挂载命名空间检查确认，移除 MagiCap 后还保留 CA Installer 的 tmpfs 层。安装脚本会将额外证书复制到 tmpfs，再绑定到 Conscrypt 目录。

| 视图 | 证书数量 |
| --- | ---: |
| MagiCap 顶层 | 152 |
| CA Installer tmpfs 下层 | 151 |
| 原始只读 Conscrypt APEX | 149 |

克隆中移除下层后，原始 APEX 由 erofs 承载；临时别名下是空目录。完整证书集合已在私有证据中核对。克隆操作前后，真实淘宝进程的 mountinfo 完全一致。

### 原始 149 张证书对照：已完成

另一份独立临时程序固定匹配本次启动中的原始 erofs APEX、f2fs 数据分区和两层覆盖。每次普通 umount 前重新核对挂载 ID、父子关系和目录 fd 的实际 mnt_id，最终要求没有目标覆层、149 个文件逐字节等于已验证的平台参考、临时别名恢复为空目录。

本次暂停 107 ms，四次限定卸载全部完成，149 个文件比对通过，三个非目标进程的挂载快照保持一致。淘宝恢复运行后，新的 mtop.trade.query.bag 仍返回 HTTP 419，后续错误为 ANDROID_SYS_API_41X_ANTI_ATTACK。记录量为 16，未达到观察上限。

这是对当前 Conscrypt APEX 视图的验证，不表示整个设备已恢复无 Root 环境，也不排除其他路径、继承状态或服务器历史判定。临时程序经 NDK 严格编译、主机 ASan/UBSan 反例校验和独立代码复核；它不在发布 APK 中。

## HMA 专属配置对照

确认 HMA-OSS 对淘宝启用了白名单、安装来源和部分设置过滤。本轮只通过现有管理界面关闭淘宝的“启用隐藏”，读回确认只移除淘宝 scope，其他配置保持一致。保留同一个设置页面中的配置对象，试验后重新启用并逐字段确认整份配置恢复原样。

HMA 停用后的新购物车请求仍为 HTTP 419 / ANDROID_SYS_API_41X_ANTI_ATTACK，20 条观察记录未达到上限。这个阴性结果不排除先前过滤所产生的持久状态。

## 组合对照

为检查多项条件同时存在的可能性，额外执行一次组合：

- MagiCap 对淘宝保持停止捕获；
- HMA 淘宝 scope 移除；
- AliLoginCompat 的淘宝作用域移除，闲鱼及模块自身保留；
- 已知 SG 库映射前，恢复原始 149 张 Conscrypt 证书。

组合试验的暂停时间为 117 ms，证书逐字节核对通过，三个非目标挂载快照未变。淘宝恢复后仍进入官方 ContainerActivity 拒绝页。

因为这次主动移除了 AliLoginCompat，状态观察器未注入，记录数为零。本次证据是实际拒绝页面，不把前一轮的 HTTP 状态当作本轮新响应，也不把没有观察记录当成成功。随后强停测试进程，原 HMA 配置和 Vector 作用域均读回确认已精确恢复。

一次未生效的界面点击曾使组合编排在试验启动前中止；当时读回确认配置未变。这次中止不计入有效试验。重新获取界面状态后的组合试验才是上述结果。

该方法先停止模块管理应用，保存原内容，再在原目录内写入临时文件，核对 owner、mode、SELinux 标签和内容摘要后原子替换。只临时开启 trace_status、关闭 deny_bubble，其他选项及原 epoch 保留。另有独立的 60 秒回滚保护，仅在当前内容仍等于本次临时版本时恢复，避免覆盖期间出现的其他修改。
